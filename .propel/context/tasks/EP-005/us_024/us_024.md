# User Story - US_024

## Story ID
* ID Format: US_024

## Story Title
* Designate a preferred appointment slot during booking

## Description
* As a **patient**, I want to mark a future available slot as my preferred alternative while booking, so that I am automatically moved to it if it becomes available while I still have an active booking.

## Acceptance Criteria

### AC-001: Patient can designate exactly one preferred slot per booking
- **Given**: A patient has a Confirmed booking and is on MOD-003 (Preferred Slot Selection)
- **When**: The patient selects a slot from the available list and clicks "Set as Preferred"
- **Then**: `POST /bookings/{bookingId}/preferred-slot` is called with the selected `slotId`, the response is HTTP 201 with `{"preferredSlotId": "<uuid>", "status": "Registered"}`, and the `preferred_slot_id` column on the booking record is updated

### AC-002: Designating a new preferred slot replaces the previous one
- **Given**: A patient already has a preferred slot on their booking
- **When**: `POST /bookings/{bookingId}/preferred-slot` is called with a different `slotId`
- **Then**: The `preferred_slot_id` is updated to the new slot and the old preferred slot designation is released — `SELECT COUNT(*) FROM preferred_slots WHERE booking_id = <id>` returns 1

### AC-003: Preferred slot cannot be the same as the currently booked slot
- **Given**: A patient is on MOD-003
- **When**: The patient attempts to select their currently booked slot as preferred
- **Then**: The UI does not include the current slot in the available list in MOD-003, and `POST /bookings/{bookingId}/preferred-slot` with the same `slotId` as the active booking returns HTTP 400 with `{"error": "Preferred slot cannot be the same as the active booking."}`

### AC-004: Preferred slot selection is only available while the booking is Confirmed
- **Given**: A booking has status `Cancelled`
- **When**: `POST /bookings/{bookingId}/preferred-slot` is called
- **Then**: The response is HTTP 409 with `{"error": "Preferred slot selection is only available for active confirmed bookings."}`

## Edge Cases
* **Selected preferred slot becomes unavailable before confirmation**: If the patient selects a slot in MOD-003 but it transitions to Booked before `POST /bookings/{bookingId}/preferred-slot` is called, the API must return HTTP 409 with `{"error": "The selected slot is no longer available."}` — MOD-003 must refresh its slot list on re-open.
* **Patient cancels booking while preferred slot is registered**: When a booking is cancelled, the background job for preferred slot monitoring (us_025) must be notified to release the preferred slot designation and make it available for other patients.
