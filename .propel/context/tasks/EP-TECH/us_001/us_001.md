# User Story - US_001

## Story ID
* ID Format: US_001

## Story Title
* Set up Docker Compose 8-service platform stack

## Description
* As a **DevOps engineer**, I want the entire platform deployable as a single `docker compose up` command, so that every developer and CI runner gets a consistent, reproducible environment with zero manual setup.

## Acceptance Criteria

### AC-001: All 8 services start successfully
- **Given**: A host machine with Docker Compose 2.x installed and `docker-compose.yml` present in the project root
- **When**: `docker compose up --wait` is executed
- **Then**: All 8 services (nginx, api, db, ollama, prometheus, grafana, seq) reach the `healthy` state within 120 seconds and no container exits with a non-zero code
- **And**: `docker compose ps` shows `Status: running (healthy)` for every service

### AC-002: PostgreSQL, Ollama, Seq, Prometheus, and Grafana use named volumes
- **Given**: The Docker Compose stack has been started and then stopped with `docker compose down` (without `--volumes`)
- **When**: `docker compose up` is run again
- **Then**: Data in `db_data`, `ollama_models`, `seq_data`, `prometheus_data`, and `grafana_data` volumes persists from the previous run
- **And**: `docker volume ls` lists all 5 named volumes

### AC-003: HTTP → HTTPS redirect enforced at Nginx
- **Given**: The stack is running with TLS certificates configured at Nginx
- **When**: A GET request is sent to `http://localhost:80/`
- **Then**: The response is HTTP 301 with `Location: https://localhost/`

### AC-004: Services restart on failure
- **Given**: Any stateful container (db, ollama, seq, prometheus, grafana) is killed with `docker kill`
- **When**: Docker evaluates the restart policy
- **Then**: The container restarts automatically within 30 seconds per the `restart: always` policy
- **And**: The dependent API container remains running during the restart

### AC-005: Nginx serves React SPA static files
- **Given**: The built React SPA static files are present in the Nginx static folder
- **When**: A GET request is made to `https://localhost/`
- **Then**: The response is HTTP 200 with `Content-Type: text/html` and the React SPA shell HTML is returned

## Edge Cases
* **Port conflicts**: If host port 80, 443, 5432, 11434, 9090, 3000, or 5341 is already in use, `docker compose up` should fail fast with a clear port binding error rather than silently binding to an alternate port.
* **Missing `.env` file**: If the `PHI_ENCRYPTION_KEY` environment variable is not set, the `db` service must fail the health check and print a descriptive error; it must not start with a null encryption key.
* **Ollama model not yet pulled**: On first start, the `ollama` container is healthy but the Llama 3.1 8B model may not yet be downloaded; the API service must not crash — it must return HTTP 503 with `{"error": "AI model not ready"}` until the pull completes.
