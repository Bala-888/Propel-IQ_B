# User Story - US_002

## Story ID
* ID Format: US_002

## Story Title
* Scaffold React 18 TypeScript SPA with routing and role shell

## Description
* As a **frontend developer**, I want a React 18 TypeScript SPA project bootstrapped with a routing skeleton and role-based redirect placeholder, so that feature teams can add pages without re-architecting the navigation or auth context.

## Acceptance Criteria

### AC-001: SPA builds and serves without errors
- **Given**: The React project is scaffolded in the `frontend/` directory with all dependencies installed
- **When**: `npm run build` is executed
- **Then**: A production build completes with zero TypeScript errors and zero ESLint errors, and the `dist/` output contains `index.html` and hashed static assets

### AC-002: Route skeleton covers all three role dashboards
- **Given**: The routing configuration is loaded
- **When**: The app is navigated to `/login`, `/intake`, `/queue`, and `/admin`
- **Then**: Each route renders its designated placeholder component without a 404 or blank screen
- **And**: The browser URL matches the exact path navigated to

### AC-003: Auth context placeholder redirects unauthenticated users
- **Given**: No authentication token is present in local state
- **When**: Any protected route (e.g., `/intake`, `/queue`, `/admin`) is accessed directly
- **Then**: The app redirects to `/login` with the original path stored as a `redirect` query parameter
- **And**: The redirect occurs client-side without a full page reload

### AC-004: Role-based post-login redirect skeleton works
- **Given**: A mock auth context provides a user with role `Patient`, `Staff`, or `Admin`
- **When**: The role-based redirect hook resolves the destination
- **Then**: `Patient` role resolves to `/intake`, `Staff` to `/queue`, and `Admin` to `/admin`

### AC-005: Google Fonts IBM Plex Sans loads in development
- **Given**: The SPA is running in development mode (`npm start`)
- **When**: The browser loads the root page
- **Then**: The computed font family for body text is `IBM Plex Sans` as confirmed in DevTools → Computed Styles

## Edge Cases
* **Unknown role value**: If the `role` claim from the JWT contains an unrecognized value (e.g., `Provider`), the redirect hook must fall back to `/login` and log a console warning rather than throwing an uncaught exception.
* **Concurrent route transitions**: Rapid back-to-back navigation calls must not cause React Router to render two routes simultaneously or leave the previous route mounted.
