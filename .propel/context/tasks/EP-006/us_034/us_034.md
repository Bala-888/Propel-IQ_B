# User Story - US_034

## Story ID
* ID Format: US_034

## Story Title
* Admin KPI metrics dashboard with user management links

## Description
* As a **clinic administrator**, I want to view key operational KPIs and navigate to user management from a single dashboard, so that I can monitor platform health and manage staff accounts without switching contexts.

## Acceptance Criteria

### AC-001: KPI dashboard renders core booking metrics for the current day
- **Given**: An authenticated Admin user navigates to SCR-016 (`/admin/kpi`)
- **When**: `GET /admin/metrics?date=today` is called
- **Then**: The dashboard displays: Total Bookings Today, Confirmed Count, Cancelled Count, Walk-ins Count, Average Wait Time (minutes), and No-show Risk Distribution (High/Medium/Low counts) — all for the current calendar day

### AC-002: KPI data refreshes every 60 seconds automatically
- **Given**: The admin is on SCR-016
- **When**: 60 seconds elapse since the last data load
- **Then**: `GET /admin/metrics?date=today` is re-called automatically, updated values are rendered in the metric cards, and no full page reload occurs

### AC-003: Navigating to User Management from the KPI dashboard leads to SCR-017
- **Given**: The admin is on SCR-016
- **When**: The admin clicks the "User Management" link or button on the dashboard
- **Then**: The browser navigates to SCR-017 (`/admin/users`) — no new tab is opened unless explicitly requested

### AC-004: Metrics API is restricted to Admin role only
- **Given**: An authenticated user with role `Staff` or `Patient` calls `GET /admin/metrics`
- **When**: The request is evaluated by the RBAC middleware
- **Then**: The response is HTTP 403 with `{"error": "Access denied. Admin role required."}` — no metric data is returned

## Edge Cases
* **No bookings exist for today**: If `GET /admin/metrics?date=today` returns all zero counts, the dashboard must display zeros in all metric cards — not an error state or loading spinner.
* **Metric aggregation query exceeds 5 seconds**: If the database aggregation takes longer than 5 seconds, the API must return HTTP 503 with `{"error": "Metrics temporarily unavailable."}` rather than a timeout exception, and the dashboard must display "Data temporarily unavailable. Refreshing..." without crashing.
