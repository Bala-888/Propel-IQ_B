# User Story - US_031

## Story ID
* ID Format: US_031

## Story Title
* Same-day patient queue dashboard with risk badges and wait-time tracking

## Description
* As a **staff member**, I want to view all patients waiting today in a single dashboard, so that I can monitor the queue, see each patient's risk tier, and prioritise care delivery efficiently.

## Acceptance Criteria

### AC-001: Queue dashboard renders all today's checked-in and confirmed patients on SCR-011
- **Given**: An authenticated Staff or Admin user navigates to `/queue`
- **When**: `GET /queue?date=today` is called
- **Then**: SCR-011 renders a table with columns: Position, Patient Name, Arrival Time, Appointment Time, Wait Time (minutes), Risk Tier badge, and Status — one row per patient with a booking or queue entry for today

### AC-002: No-show risk tier badge displays text label alongside colour indicator
- **Given**: A queue row for a patient with `no_show_risk_tier = "High"` is rendered
- **When**: The row is displayed
- **Then**: The risk badge shows a red background with both the text `"High Risk"` and an icon (e.g., warning triangle) — not color alone — meeting UXR-403 and UXR-105

### AC-003: Wait time is calculated in real time and updates without a page reload
- **Given**: A patient's `arrival_time` is set and `appointment_time` has not yet arrived
- **When**: The queue dashboard is open
- **Then**: The Wait Time cell updates every 30 seconds via a client-side interval without a full page reload — the displayed value matches `now - arrival_time` in whole minutes

### AC-004: Queue is sortable by Position, Wait Time, and Risk Tier
- **Given**: The queue table is rendered with at least 5 rows
- **When**: A staff member clicks the column header for "Risk Tier"
- **Then**: The rows re-sort by risk tier in descending order (High → Medium → Low) and the column header shows a sort indicator arrow

### AC-005: Queue shows summary counts at the top
- **Given**: 12 patients are in the queue (4 High, 5 Medium, 3 Low risk)
- **When**: SCR-011 renders
- **Then**: A summary bar displays `"12 Waiting | 4 High Risk | 5 Medium Risk | 3 Low Risk"` — counts update when the queue data refreshes

## Edge Cases
* **Queue is empty for today**: If no patients are checked in or confirmed for today, SCR-011 must display "No patients in queue for today." in the table area — not an empty table with headers only.
* **Patient appears in queue with missing risk score**: If `no_show_risk_tier = null`, the badge must show `"Unknown"` with a neutral grey indicator, not a blank cell.
