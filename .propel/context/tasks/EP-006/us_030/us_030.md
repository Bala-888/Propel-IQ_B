# User Story - US_030

## Story ID
* ID Format: US_030

## Story Title
* Staff walk-in booking form with same-day slot assignment

## Description
* As a **staff member**, I want to create an immediate walk-in booking for a patient who presents in person, so that they are added to the queue and assigned a same-day slot without going through the self-service flow.

## Acceptance Criteria

### AC-001: Walk-in booking form renders on SCR-012 for authenticated staff
- **Given**: An authenticated user with role `Staff` or `Admin` navigates to `/walkin/new`
- **When**: SCR-012 (Walk-in Booking Form) loads
- **Then**: The form displays fields: Patient Search (typeahead), Reason for Visit (required), Slot Assignment (dropdown of today's Available slots), and Priority (Normal/Urgent) — all within a single page, no multi-step wizard

### AC-002: Existing patient is found and selected via typeahead search
- **Given**: A staff member types at least 3 characters in the Patient Search field
- **When**: The input triggers `GET /patients/search?q=<term>`
- **Then**: Matching patient records are shown as dropdown suggestions within 500ms, and selecting one pre-fills the patient ID and displays the patient's name and DOB for confirmation

### AC-003: Submitting the walk-in form creates a Confirmed booking and queues the patient
- **Given**: All required fields are completed and a valid slot is selected
- **When**: The staff member clicks "Create Walk-in"
- **Then**: `POST /bookings/walkin` is called, returns HTTP 201 with `{"bookingId": "<uuid>", "status": "Confirmed", "queuePosition": <int>}`, the patient appears in the queue on SCR-011, and the assigned slot transitions to `status = "Booked"`

### AC-004: Walk-in for a new patient triggers account creation modal before booking
- **Given**: The staff member searches for a patient but no matching record is found
- **When**: The staff member clicks "Create New Patient" in the typeahead dropdown
- **Then**: MOD-004 (Walk-in Account Creation) opens, the staff member fills the minimum required fields, submits to create the patient record, and MOD-004 closes with the new patient ID pre-filled in the walk-in form

## Edge Cases
* **No available same-day slots**: If no slots have `status = "Available"` for today, the Slot Assignment dropdown shows "No same-day slots available" and the Create Walk-in button is disabled — the staff member must be shown a message "All same-day slots are full. Consider adding the patient to a wait list."
* **Duplicate walk-in booking for the same patient on the same day**: If a Confirmed booking already exists for the same patient on today's date, the form must display a warning banner "This patient already has a confirmed booking today." before the staff member can override and proceed.
