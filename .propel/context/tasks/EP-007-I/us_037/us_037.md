# User Story - US_037

## Story ID
* ID Format: US_037

## Story Title
* Generate Ollama text embeddings for document chunks and store in pgvector

## Description
* As a **platform system**, I want each document chunk to be converted into a vector embedding via Ollama and stored in pgvector, so that semantic similarity search across patient documents is available for downstream AI features.

## Acceptance Criteria

### AC-001: Embedding is generated for each chunk when status is "Chunked"
- **Given**: `document_records.status = "Chunked"` and `document_chunks` rows exist for the document
- **When**: The `EmbeddingService` consumes the `DocumentChunked` event
- **Then**: For each chunk, `POST /api/embeddings` is called on the Ollama local endpoint with `{"model": "llama3.1:8b", "input": "<chunk.content>"}`, and the response vector is received

### AC-002: Embedding vector is stored in the `chunk_embeddings` table
- **Given**: The Ollama API returns a 1,536-dimension float vector for a chunk
- **When**: The embedding pipeline persists the result
- **Then**: A row is inserted in `chunk_embeddings` with `chunk_id`, `embedding` (type `vector(1536)`), and `created_at` — one row per chunk, no duplicates

### AC-003: pgvector cosine similarity index is created and used for search
- **Given**: Embeddings are stored in `chunk_embeddings.embedding`
- **When**: A semantic search query `SELECT chunk_id, 1 - (embedding <=> $1::vector) AS similarity FROM chunk_embeddings ORDER BY similarity DESC LIMIT 5` is executed
- **Then**: The query uses the HNSW index (created in the EP-DATA migrations) and completes within 200ms for a corpus of 10,000 chunks

### AC-004: Embedding failure for an individual chunk is retried once then logged
- **Given**: The Ollama API returns a 5xx error for one chunk in a batch
- **When**: The embedding service processes that chunk
- **Then**: One retry is attempted after a 10-second delay; if the retry also fails, the chunk row in `chunk_embeddings` is skipped and `document_records.status` retains `"Chunked"` — a Seq log entry is written with `level = "Error"` and `eventType = "EmbeddingFailed"` with the `chunkId`

## Edge Cases
* **Ollama service is offline at embedding time**: If the Ollama endpoint returns a connection refused error, the batch must stop processing and the `DocumentChunked` event must be re-queued for retry after a 5-minute back-off — not dropped silently.
* **Vector dimension mismatch**: If the Ollama model returns a vector with a dimension other than 1,536, the insert must be rejected at the application layer with a validation error logged — do not attempt to insert a malformed vector into pgvector which would cause a cast exception.
