## Task Overview

Build the `IConfirmationPdfService` and its QuestPDF document template. The service accepts a `ConfirmationData` record and renders a single-page PDF containing all mandatory AC-002 fields. The QR code image is generated by Net.QRCoder (PNG bytes) and embedded in the document layout as a fixed-size image cell. PDF generation runs inside `Task.Run` to avoid blocking async I/O threads. The `CancellationToken` parameter allows the caller to impose the 10-second timeout and receive an `OperationCanceledException` if rendering exceeds the budget.

## Implementation Plan
1. Add NuGet packages: `QuestPDF` (latest stable, community licence free for open-source) and `QRCoder` (Net.QRCoder, MIT) to the API project; register `IConfirmationPdfService` as scoped in `Program.cs` (AC-002)
2. Define `ConfirmationData` record: `string PatientFullName`, `DateTimeOffset AppointmentDateTime`, `string ClinicName`, `string ClinicAddress`, `string? ProviderName`, `Guid BookingReferenceId` — no medical or intake fields; scheduling identity data only (AC-002; OWASP A02 — minimum-necessary data in document)
3. Implement `ConfirmationPdfDocument : IDocument`: `DocumentMetaData()` returns `{ Title = "Appointment Confirmation", Author = "Clinic System" }`; `Compose(IDocumentContainer container)` defines a single page with top padding, header section, and content section (AC-002)
4. Header section: render clinic name in heading style; render the text "Appointment Confirmation" as a subtitle (AC-002 — clinic name)
5. Content section: render each mandatory field in a labelled row: "Patient" → `data.PatientFullName`; "Date & Time" → `data.AppointmentDateTime.ToString("dddd, MMMM d, yyyy 'at' h:mm tt")`; "Location" → `data.ClinicAddress`; "Provider" → `data.ProviderName ?? "To be assigned"`; "Reference" → `data.BookingReferenceId.ToString()` (AC-002)
6. QR code cell: `using var qrGenerator = new QRCodeGenerator(); var qrData = qrGenerator.CreateQrCode(data.BookingReferenceId.ToString(), QRCodeGenerator.ECCLevel.Q); var pngBytes = new PngByteQRCode(qrData).GetGraphic(5);` — embed `pngBytes` as a 60×60-point `Image` element in the bottom-right of the content section (AC-002)
7. `IConfirmationPdfService.GenerateAsync(ConfirmationData data, CancellationToken ct)`: wraps `Document.Create(c => new ConfirmationPdfDocument(data).Compose(c)).GeneratePdf()` inside `Task.Run(() => ..., ct)` so that the QuestPDF synchronous render runs on a ThreadPool thread; the `CancellationToken` is passed to `Task.Run` — if the token is cancelled before the task starts, `OperationCanceledException` is thrown; if cancelled mid-render, the exception propagates to the caller (AC-002; Edge: PDF timeout — `OperationCanceledException` propagation)

- [ ] Open the rendered PDF; verify all 6 mandatory fields are present: patient name, date/time, clinic name, clinic address, provider name (or "To be assigned"), booking reference GUID (AC-002)

- [ ] Call `GenerateAsync` with an already-cancelled `CancellationToken`; verify `OperationCanceledException` is thrown immediately (Edge: PDF timeout — cancellation propagation)
- [ ] Verify `ConfirmationData` contains no medical diagnosis, medication, or intake fields — only scheduling and identity data (OWASP A02; HIPAA)

## Implementation Checklist
- [ ] `ConfirmationData` record contains only scheduling and identity fields (PatientFullName, AppointmentDateTime, ClinicName, ClinicAddress, ProviderName?, BookingReferenceId); no medical history, medication, or intake data is included in the PDF document (OWASP A02; HIPAA minimum-necessary)
- [ ] `ConfirmationPdfDocument.Compose` renders all 6 AC-002 mandatory fields: patient full name, appointment date/time, clinic name, clinic address, provider name (nullable — defaults to "To be assigned"), booking reference ID as text (AC-002)
- [ ] QR code is generated from `data.BookingReferenceId.ToString()` using `PngByteQRCode.GetGraphic(5)` and embedded as an `Image` element; the `QRCodeGenerator` and `PngByteQRCode` instances are created and disposed within the `Compose` method using `using` declarations (AC-002; resource management)
- [ ] `GenerateAsync` wraps the synchronous `Document.Create(...).GeneratePdf()` call inside `Task.Run(() => ..., ct)`; the `CancellationToken` is passed directly to `Task.Run` — cancellation before task start throws `OperationCanceledException` which propagates to the caller without being swallowed (AC-002; Edge: PDF timeout)
- [ ] `IConfirmationPdfService` is registered as scoped (`AddScoped`) not singleton; QuestPDF document instances are created per call (no shared state across concurrent requests) (DI correctness; OWASP A04)
