# User Story - US_022

## Story ID
* ID Format: US_022

## Story Title
* Generate QuestPDF booking confirmation and dispatch via SMTP email

## Description
* As a **patient**, I want to receive a PDF booking confirmation by email immediately after I book, so that I have an official record of my appointment details.

## Acceptance Criteria

### AC-001: Confirmation email with PDF attachment is sent within 60 seconds of booking
- **Given**: A confirmed booking is created
- **When**: The `BookingConfirmed` domain event is handled by the `ConfirmationEmailService`
- **Then**: The patient's email address on record receives an email with subject `"Appointment Confirmed – <Date>"`, the email body contains the appointment date/time and clinic location, and a QuestPDF-generated PDF is attached with file name `confirmation-<bookingId>.pdf` — all within 60 seconds

### AC-002: PDF document contains all mandatory data fields
- **Given**: The QuestPDF generation pipeline renders the confirmation document
- **When**: The document byte stream is serialised
- **Then**: The PDF contains: patient full name, appointment date/time, clinic name and address, provider name (if assigned), booking reference ID, and a QR code encoding the booking reference

### AC-003: SMTP failure is retried up to 3 times before logging a permanent failure
- **Given**: The SMTP server is unreachable on the first send attempt
- **When**: The email dispatch service processes the event
- **Then**: It retries at 30-second, 60-second, and 120-second intervals; after 3 failed retries, it logs `level = "Error"`, `eventType = "ConfirmationEmailFailed"` to Seq — the booking status remains `Confirmed` regardless of email outcome

### AC-004: Email is not sent if the patient has opted out of email notifications
- **Given**: The patient's preferences record has `email_notifications_enabled = false`
- **When**: The `ConfirmationEmailService` processes the event
- **Then**: No email is dispatched, the Seq log records `eventType = "ConfirmationEmailSkipped"` with `reason = "OptedOut"`, and no SMTP connection is opened

## Edge Cases
* **Patient email address is malformed in the database**: If the stored email fails RFC 5322 format validation, the service must log `eventType = "ConfirmationEmailFailed"` with `reason = "InvalidEmailAddress"` and skip all retry attempts.
* **PDF generation exceeds 10 seconds**: If the QuestPDF rendering pipeline does not complete within 10 seconds, the service must log `eventType = "PdfGenerationTimeout"`, send the email without the attachment (with body text "Your confirmation document is being generated and will follow shortly"), and trigger a separate deferred PDF delivery job.
